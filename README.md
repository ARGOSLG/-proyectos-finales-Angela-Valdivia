# Proyecto ARGOS

Plataforma B2B con telemetría mecánica periférica, correlación contextual de riesgo y bypass crítico en tiempo real (< 2s) para mitigar el asalto en tránsito.

## Objetivo del Proyecto

Desarrollar una plataforma B2B de seguridad operacional para el autotransporte de carga terrestre, que integra sensores IoT (5ª rueda, patines y asiento de cabina) con telemetría y correlación contextual de riesgo, para detectar asaltos y desenganches en tiempo real y reducir el tiempo de respuesta ante incidentes de 15-45 minutos a menos de 2 segundos.

## Tecnologías Utilizadas

- **Sistema Web y Backend:** Desarrollado íntegramente con **Laravel**.
- **Base de Datos:** **PostgreSQL** para la persistencia, seguridad y gestión de la información.
- **Aplicación Móvil:** Construida con **React Expo**, la cual consume a través de una API los servicios expuestos por el sistema web.

## Resultado obtenido
Se diseñó una arquitectura completa (hardware IoT, backend en Laravel/Redis, infraestructura AWS Zero-Trust y app móvil) con un modelo de negocio validado: ROI del 404% en el primer año, payback operativo de 0.81 meses y reducción del 99% en horas-hombre de monitoreo y tiempo de respuesta ante incidentes.
