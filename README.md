# Proyecto ARGOS

Sistema web integral y aplicación móvil diseñados para optimizar la gestión y operación del proyecto ARGOS.

## Tecnologías Utilizadas

- **Sistema Web y Backend:** Desarrollado íntegramente con **Laravel**.
- **Base de Datos:** **PostgreSQL** para la persistencia, seguridad y gestión de la información.
- **Aplicación Móvil:** Construida con **React Expo**, la cual consume a través de una API los servicios expuestos por el sistema web.
